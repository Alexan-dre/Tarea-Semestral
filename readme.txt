Instrucciones de ejecución:
1.  Asegurarse de que el archivo de código .ipynb y el archivo (spanishc-t.json) se encuentren en la misma carpeta
2.  Ejecutar el programa desde Jupyter Notebook sobre Windows
3.  Al iniciar, el programa solicitará palabras que se utilizarán en el juego. Ingrese cada palabra que desea añadir y presione Enter.
4.  Cada  palabra se contrastará con el archivo spanishc-t.json. Si la palabra no se encuentra, el sistema solicitará confirmación para utilizarla. Para responder puede utilizar 'si' o 's', sin distinción de mayúsculas ni tildes, cualquier otra entrada se considerará un 'no'.
5. Para finalizar la base de datos, presione 'Enter' sin escribir nada
6.  El computador elegirá una palabra al azar de las ingresadas
7. El jugador debe ingresar una letra a la vez, la letra no deberá tener tildes. El progreso se mostrará mediante una representación gráfica del ahorcado.
8. El jugador dispone de 10 intentos. El juego finalizará cuando el jugador adivine la palabra o se quede sin intentos.
9. Al finalizar se le preguntará si quiere volver a jugar, responda de la misma forma que se detalla en la instrucción 4.
